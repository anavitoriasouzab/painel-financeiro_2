Política de Privacidade

Última atualização: 2026-09-05

1. Introdução e controlador dos dados

Esta política explica como o Painel Financeiro coleta, usa, armazena e protege os dados pessoais e financeiros de quem usa o app, em conformidade com a Lei Geral de Proteção de Dados (LGPD, Lei 13.709/2018). Ao usar o app, você concorda com o tratamento de dados descrito aqui.

2. Quais dados coletamos

  • Dados de conta: e-mail, nome (quando informado) e, se você entrar com Google, as informações básicas de perfil fornecidas pelo Google (nome, e-mail, foto).
  • Dados financeiros cadastrados por você: renda, despesas fixas e variáveis, parcelamentos, cartões, metas, reserva de emergência, categorias e histórico mensal.
  • Preferências de uso: tema claro/escuro e outras configurações de interface, guardadas localmente no seu navegador.

Não coletamos dados de localização, contatos, câmera/microfone, nem fazemos rastreamento para fins de publicidade.

3. Base legal para o tratamento

Tratamos seus dados com base (i) na execução de contrato — é necessário processar seus dados financeiros para o app funcionar — e (ii) no consentimento que você dá ao aceitar estes termos no cadastro (ou no primeiro acesso, para contas já existentes).

4. Para que usamos seus dados

Exclusivamente para operar o app: calcular e exibir seu painel financeiro, gráficos, projeções, lembretes e simulações. Não vendemos, alugamos nem compartilhamos seus dados financeiros com terceiros para fins de marketing ou publicidade.

5. Onde e como seus dados ficam guardados

Os dados são armazenados no Supabase (infraestrutura de banco de dados e autenticação, atuando como operador de dados nos termos da LGPD), com Row Level Security ativado em todas as tabelas — cada conta só consegue ler e editar os próprios dados, mesmo a nível de banco de dados, não apenas na interface do app. A comunicação entre o app e o banco de dados é feita por conexão criptografada (HTTPS/TLS).

6. Por quanto tempo guardamos seus dados

Seus dados ficam armazenados enquanto sua conta existir. Ao excluir sua conta (Perfil → Excluir todos os dados), todos os dados financeiros associados a ela são apagados permanentemente do banco de dados.

7. Seus direitos como titular dos dados (LGPD)

Você pode, a qualquer momento, diretamente no app:

  • Acessar e exportar uma cópia de todos os seus dados (Perfil → Backup, formato JSON);
  • Corrigir qualquer informação incorreta, editando-a diretamente nas telas do app;
  • Excluir permanentemente todos os seus dados (Perfil → Excluir todos os dados);
  • Revogar o consentimento, o que implica encerrar sua conta, já que o tratamento dos dados financeiros é necessário para o funcionamento do serviço.

Para outras solicitações relacionadas aos seus dados (portabilidade, informações sobre compartilhamento etc.), entre em contato pelo e-mail informado na seção 10.

8. Compartilhamento com terceiros

Só compartilhamos dados com prestadores de serviço estritamente necessários para operar o app:

  • Supabase — hospedagem do banco de dados e autenticação;
  • Google — apenas se você optar por entrar/cadastrar com sua conta Google (login via OAuth).

Não compartilhamos seus dados financeiros com nenhum outro terceiro, e não os utilizamos para treinar modelos de terceiros.

9. Cookies e armazenamento local

O app usa localStorage do navegador apenas para preferências de interface (tema claro/escuro) e para manter sua sessão de autenticação ativa — não para rastreamento, perfilamento ou publicidade. Nenhum cookie de terceiros é usado pelo app em si (fontes do Google Fonts podem ser carregadas do próprio Google, sujeitas à política de privacidade do Google).

10. Contato e encarregado de dados

Dúvidas, solicitações ou reclamações sobre esta política podem ser enviadas para ana.dev2026@gmail.com.

11. Alterações nesta política

Podemos atualizar esta Política de Privacidade periodicamente. Mudanças relevantes serão comunicadas dentro do app, e o uso continuado do serviço após uma atualização representa ciência da nova versão.
